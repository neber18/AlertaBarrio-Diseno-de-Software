## HU_014 — Confirmar una alerta

**Como** vecino,
**quiero** confirmar que una alerta publicada es real,
**para** que la comunidad sepa que es confiable.

| Campo | Valor |
|-------|-------|
| Épica | EP-04 Alertas comunitarias |
| Prioridad | Media (Should) |
| Estimación | 2 puntos de historia |
| Requisitos relacionados | RF-21 |

### Criterios de aceptación

- [ ] Solo se pueden confirmar alertas publicadas o verificadas.
- [ ] Un vecino no puede confirmar su propio reporte ni confirmar dos veces el mismo.
- [ ] Con 2 confirmaciones (configurable), la alerta pasa a verified.

### Definición de Terminado

- [ ] Código revisado (pull request)
- [ ] Pruebas aprobadas en GitHub Actions
- [ ] Criterios de aceptación verificados
